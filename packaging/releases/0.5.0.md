# Fy1Sync 0.5.0

## 更新内容

- 新增画面匹配自动对齐模式, 直接比对两路相同视角的画面计算偏移 (不限游戏), 支持裁剪比对范围与设置忽略区域; 原样式包识别模式自动迁移为基础模式, 样式包与编辑器从主播放器拆出.
- 扩充多平台弹幕与房间活动支持: 新增哔哩哔哩实时弹幕与天选福袋只读卡片及提醒, 接入斗鱼主播抽奖, 抖音普通福袋与虎牙上电视只读卡片及提醒, 新增抖音登录后发送文字弹幕, 统一自动与手动弹幕房间归属规则.
- 完善账号登录与凭据导入: 新增 Windows 浏览器已登录账号导入, 抖音内嵌登录改用官方专属登录页并实时刷新发送检查状态, 应用内登录与导入的国内平台账号支持读取并展示头像和昵称; 修复增强画中画发送栏权限控制与斗鱼长时间播放时观时上报断连后的自动恢复.
- 新增独立直播间收藏夹面板 (支持搜索, 平台筛选与后台开播状态采集), 新增一键恢复上次画面和解说, 同屏观看新增左右分屏 (默认), 上下分屏和自定义比例, 主播摄像头框选按直播间稳定身份记忆恢复.
- CS2 赛程与战队队标改经缓存中转服务 (`schedule.fy1ng.cn`) 提供, 客户端不再直连 Liquipedia 触发限流与人机验证.
- 梳理界面交互与文案: 新增可自定义快捷键设置页 (`设置 -> 通用 -> 快捷键`), 对齐偏移统一为画面视角 (`画面延后` / `画面提前`), 小画面隐藏后常显找回按钮, 斗鱼任务支持添加并启动与行内反馈且时间单位改用秒, 网络设置改为草稿保存加离开确认, 合并关于页更新入口, 移除打开本地视频文件入口.

## 下载选择

| 系统 | 架构 | 安装包 | 便携包 |
| --- | --- | --- | --- |
| Windows | x64 | `win-x64-nsis.exe` | `win-x64-portable.zip` |
| macOS 13+ | Intel x64 | `mac-x64.dmg` | `mac-x64.zip` |
| macOS 13+ | Apple Silicon arm64 | `mac-arm64.dmg` | `mac-arm64.zip` |
| Linux | x64 | `linux-x64.deb` | `linux-x64.AppImage`, `linux-x64.tar.gz` |
| Linux | arm64 | `linux-arm64.deb` | `linux-arm64.AppImage`, `linux-arm64.tar.gz` |

文件名均带有 `Fy1Sync-0.5.0-` 前缀. `SHA256SUMS.txt` 包含全部 12 个文件的校验值.

Windows ARM64 可使用 x64 兼容环境运行本版 Windows 包. Linux 构建基线为 Ubuntu 22.04 / glibc 2.35, 需要桌面图形环境, GTK 3, NSS, ALSA, GBM 和 GnuTLS 30. AppImage 不要求安装, 运行时可能需要 FUSE 2; 也可使用 `--appimage-extract-and-run` 或选择 tar.gz. DEB 安装会声明运行依赖.

macOS 包未配置 Apple Developer ID 签名及公证. 首次运行可能受到 Gatekeeper 限制, 请按系统安全设置确认来源后打开. CI 中的原生构建和启动检查不等同于 Developer ID 签名或全部硬件与系统版本的实机验收.

抖音登录后支持发送文字弹幕; 斗鱼发送弹幕, 赠礼, 签到任务等实验性账号写操作默认关闭, 需在设置中手动开启.

Windows NSIS 支持覆盖升级并保留用户数据. 本版扩展了收藏记录文件 (`rooms/saved.json`) 的字段; 升级后若需退回 `v0.4.1`, 请先备份用户数据目录中的 `rooms/saved.json`, 否则旧版会将收藏显示为空并在新增收藏时覆盖原文件. ZIP/tar.gz 为解压运行包, 不承诺将全部用户数据保存在解压目录中. 升级前退出旧进程, 不要同时运行共享同一用户数据目录的多个版本.
