# Fy1Sync 0.5.1

## 更新内容

- 修复 macOS 安装包 (`mac-arm64` 与 `mac-x64` 的 `.dmg` 和 `.zip`) 在未配置 Apple 证书时跳过重签名且 `Contents/` 根目录散落许可文件, 导致应用包签名处于失效损坏状态的问题; 现默认完成离线 Ad-Hoc 应用包密封签名, 并将 Electron/Chromium 许可文件统一放入 `Contents/Resources/`, 同时保持内置 `yt-dlp` 与原生 FFmpeg 校验值不变.
- 新增 macOS 打包检查门禁: 对解包 `.app`, 只读挂载的 `.dmg` 内 `.app` 与解压的 `.zip` 内 `.app` 分别执行 `codesign --verify --deep --strict` 深度签名与 Bundle ID 核验.
- 更新文档中 macOS (尤其是 Apple Silicon M1–M4 与 macOS 15 及以上) 首次打开被系统隔离属性拦截时的处理说明.

## 下载选择

| 系统 | 架构 | 安装包 | 便携包 |
| --- | --- | --- | --- |
| Windows | x64 | `win-x64-nsis.exe` | `win-x64-portable.zip` |
| macOS 13+ | Intel x64 | `mac-x64.dmg` | `mac-x64.zip` |
| macOS 13+ | Apple Silicon arm64 | `mac-arm64.dmg` | `mac-arm64.zip` |
| Linux | x64 | `linux-x64.deb` | `linux-x64.AppImage`, `linux-x64.tar.gz` |
| Linux | arm64 | `linux-arm64.deb` | `linux-arm64.AppImage`, `linux-arm64.tar.gz` |

文件名均带有 `Fy1Sync-0.5.1-` 前缀. `SHA256SUMS.txt` 包含全部 12 个文件的校验值.

Windows ARM64 可使用 x64 兼容环境运行本版 Windows 包. Linux 构建基线为 Ubuntu 22.04 / glibc 2.35, 需要桌面图形环境, GTK 3, NSS, ALSA, GBM 和 GnuTLS 30. AppImage 不要求安装, 运行时可能需要 FUSE 2; 也可使用 `--appimage-extract-and-run` 或选择 tar.gz. DEB 安装会声明运行依赖.

macOS 包已完成本地 Ad-Hoc 应用包密封签名, 未配置 Apple Developer ID 付费证书及公证. 首次运行若提示无法验证开发者, 请在系统设置 -> 隐私与安全性中确认来源后打开; 若在 Apple Silicon (M1–M4) 或 macOS 15 及以上因浏览器下载附加隔离属性而提示“已损坏, 无法打开”, 请先将 `Fy1Sync.app` 拖入 `/Applications` (应用程序文件夹), 再打开终端执行 `xattr -rd com.apple.quarantine /Applications/Fy1Sync.app` 后打开. CI 中的原生构建和启动检查不等同于 Developer ID 签名或全部硬件与系统版本的实机验收.

抖音登录后支持发送文字弹幕; 斗鱼发送弹幕, 赠礼, 签到任务等实验性账号写操作默认关闭, 需在设置中手动开启.

Windows NSIS 支持覆盖升级并保留用户数据. `0.5.x` 扩展了收藏记录文件 (`rooms/saved.json`) 的字段; 若需退回 `v0.4.1`, 请先备份用户数据目录中的 `rooms/saved.json`, 否则旧版会将收藏显示为空并在新增收藏时覆盖原文件. ZIP/tar.gz 为解压运行包, 不承诺将全部用户数据保存在解压目录中. 升级前退出旧进程, 不要同时运行共享同一用户数据目录的多个版本.
