# Fy1Sync 0.4.1

## 更新内容

- 斗鱼, 哔哩哔哩, 虎牙和抖音使用统一的应用内登录卡片, 保留扫码, 短信/密码, 验证码及二次安全验证, 各平台账号会话继续隔离.
- 修复抖音分享短链接包含下划线或连字符时被拒绝的问题, 可直接粘贴完整直播分享文案. 解析成功后可收藏正式直播间地址, 同一公开房间的倒计时区域缓存可跨直播会话复用.
- 完善斗鱼观时上报状态, 粉丝牌累计观看及开播/轮播状态展示, 补充播放状态与主进程处理的回归验证.
- 补充倒计时识别及创作工具的验证覆盖, 完善 Linux 媒体工具更新测试, 保留 macOS/Linux 原生打包和发布检查.
- 修复抖音原生身份验证区域的显示与等待时序, 只有官方身份验证完成后才接收登录状态.

## 下载选择

| 系统 | 架构 | 安装包 | 便携包 |
| --- | --- | --- | --- |
| Windows | x64 | `win-x64-nsis.exe` | `win-x64-portable.zip` |
| macOS 13+ | Intel x64 | `mac-x64.dmg` | `mac-x64.zip` |
| macOS 13+ | Apple Silicon arm64 | `mac-arm64.dmg` | `mac-arm64.zip` |
| Linux | x64 | `linux-x64.deb` | `linux-x64.AppImage`, `linux-x64.tar.gz` |
| Linux | arm64 | `linux-arm64.deb` | `linux-arm64.AppImage`, `linux-arm64.tar.gz` |

文件名均带有 `Fy1Sync-0.4.1-` 前缀. `SHA256SUMS.txt` 包含全部 12 个文件的校验值.

Windows ARM64 可使用 x64 兼容环境运行本版 Windows 包. Linux 构建基线为 Ubuntu 22.04 / glibc 2.35, 需要桌面图形环境, GTK 3, NSS, ALSA, GBM 和 GnuTLS 30. AppImage 不要求安装, 运行时可能需要 FUSE 2; 也可使用 `--appimage-extract-and-run` 或选择 tar.gz. DEB 安装会声明运行依赖.

macOS 包未配置 Apple Developer ID 签名及公证. 首次运行可能受到 Gatekeeper 限制, 请按系统安全设置确认来源后打开. CI 中的原生构建和启动检查不等同于 Developer ID 签名或全部硬件与系统版本的实机验收.

抖音登录及二次验证已通过离线和桌面测试, 最终真实账号登录状态尚未完成验收. 本版只提供抖音只读弹幕, 不执行发送, 赠礼等账号写操作.

Windows NSIS 支持覆盖升级并保留用户数据. ZIP/tar.gz 为解压运行包, 不承诺将全部用户数据保存在解压目录中. 升级前退出旧进程, 不要同时运行共享同一用户数据目录的多个版本.
