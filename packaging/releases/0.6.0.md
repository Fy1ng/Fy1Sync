# Fy1Sync 0.6.0

## 更新内容

- 重构自动对齐与播放同步体验: 统一采用画面匹配对齐引擎 (移除旧 CS2 回合倒计时基础识别模式及“适配中”角标), 新增双路画面可视化拖拽裁剪有效范围与同步标注忽略区域 (`调整匹配区域`), 自动对齐改为全程后台静默执行不强制弹起底栏; 新增贴近已加载缓存末端的 `同步时间` (`4` 秒内按 `1.25×` 平滑加速追帧, 超过 `4` 秒或落后端仅向前跳转、绝不倒退), 微调按钮统一为 `回退画面` / `回退解说` 并补充手动输入面板快捷步进与大延迟/非同一对局/缓冲不足提示.
- 新增 Twitch 账号登录与广告时段提示: 支持 Twitch 应用内登录与本机浏览器登录态导入以获取 `1440P+` 高画质流; 自动识别 Twitch 官方流内嵌的 `Commercial Break` 广告时段, 在主画面、片源面板、副画面小窗与同屏窗口提示等待广告结束自动恢复.
- 支持纯直播流直链并增强长时播放稳定性: 支持直接载入 `m3u8`, `flv`, `ts` 等 HTTP/HTTPS 纯直播流地址并自定义名称、`Referer`、`User-Agent` 及请求头 (支持收藏夹保存与恢复); 升级内置精简 LGPL `FFmpeg` 至 `9.1` 与 `yt-dlp` 至 `2026.11.23` (应用内 `yt-dlp` 更新改走系统代理并支持下载进度条与取消); 支持 YouTube 分离 HLS 直播音视频双路复用与代理波动平滑重连, 自动降级保底锁定 `1080p`, 持续卡顿时自动检索匹配的虎牙官方比赛流提示一键切换; 虎牙保留多线路并在卡死时自动轮换 CDN.
- 优化清晰度菜单、弹幕显示行数与小窗缩放: 未登录观看斗鱼、哔哩哔哩时直接在清晰度菜单置灰受限高画质并标注 `需登录` (登录后即时解锁), 清理单画质无效菜单并在切换画质期间保持底栏常驻; 支持按画面高度自定义弹幕最大显示行数 (`1 行` 至 `不限`), 默认将弹幕置于主播摄像头小窗上方且悬停、拖拽互不冲突; 主播摄像头小窗与副画面小窗均支持任意拖放、四边四角八向等比缩放及位置比例记忆.
- 增强多浏览器登录与凭据导入: 独立浏览器窗口登录支持按 `Chrome -> Edge -> Firefox` 自动选用已安装浏览器, 浏览器导入补齐 Edge Canary 支持、遇到浏览器占用锁定时支持二次确认后一键关闭对应浏览器重试, 导入抖音登录态时同步提取本地存储弹幕签名密钥, 保护已验证的 YouTube 官方登录态不被覆盖并识别失效 Cookie, 登录或导入后即时刷新当前页状态, 精简斗鱼账号重命名入口.
- 优化 CS2 赛程与在线更新网络兼容: 修复多阶段赛事子页 (如 Major 各阶段) 赛事等级继承并调整赛程列表优先按 `Live` 进行中再按赛事等级排序; 将赛程与队标请求从国内平台直连开关剥离并固定直连中转服务, 移除刷新按钮倒计时锁死改为后台静默退避, 细化断网、证书拦截与服务维护错误提示并标注时区; 在线更新兼容系统代理与任意单播 TUN / Fake-IP 网段.
- 补齐启动自愈、快捷键总开关与安装上手指引: 新增启动哨兵、瞬态 GPU/着色器缓存定向清理与损坏配置文件隔离自愈 (保留账号登录凭据), 消除冷启动白屏闪烁并记录本地启动与崩溃日志, Windows 主进程启动失败补充原生错误弹窗与安装向导拦截提示; `设置 -> 通用 -> 快捷键` 新增 `启用快捷键` 总开关 (关闭后仍保留 `← / →` 主画面进退); macOS `.dmg` 内置首次打开三步文字指引背景图 (`xattr -cr /Applications/Fy1Sync.app`), 发布说明置顶多平台直链下载按钮并支持 GitCode 镜像同步, 常规报错隐藏原始 JSON 按钮并将快捷操作排为单行.

## 下载选择

| 系统 | 架构 | 安装包 | 便携包 |
| --- | --- | --- | --- |
| Windows | x64 | `win-x64-nsis.exe` | `win-x64-portable.zip` |
| macOS 13+ | Intel x64 | `mac-x64.dmg` | `mac-x64.zip` |
| macOS 13+ | Apple Silicon arm64 | `mac-arm64.dmg` | `mac-arm64.zip` |
| Linux | x64 | `linux-x64.deb` | `linux-x64.AppImage`, `linux-x64.tar.gz` |
| Linux | arm64 | `linux-arm64.deb` | `linux-arm64.AppImage`, `linux-arm64.tar.gz` |

文件名均带有 `Fy1Sync-0.6.0-` 前缀. `SHA256SUMS.txt` 包含全部 12 个文件的校验值.

Windows ARM64 可使用 x64 兼容环境运行本版 Windows 包. Linux 构建基线为 Ubuntu 22.04 / glibc 2.35, 需要桌面图形环境, GTK 3, NSS, ALSA, GBM 和 GnuTLS 30. AppImage 不要求安装, 运行时可能需要 FUSE 2; 也可使用 `--appimage-extract-and-run` 或选择 tar.gz. DEB 安装会声明运行依赖.

macOS 包已完成本地 Ad-Hoc 应用包密封签名并内置 `.dmg` 首次打开指引背景图, 未配置苹果付费开发者证书及公证. 请先将 `Fy1Sync.app` 拖入 `/Applications` (应用程序文件夹, 不要在 `.dmg` 挂载窗口内直接双击), 若因浏览器下载附加隔离属性提示“已损坏, 无法打开”, 打开终端执行一次 `xattr -cr /Applications/Fy1Sync.app` 后重新打开即可; 若提示无法验证开发者, 请在系统设置 -> 隐私与安全性中点击仍要打开. CI 中的原生构建和启动检查不等同于付费证书公证或全部硬件与系统版本的实机验收.

抖音登录后支持发送文字弹幕; 斗鱼发送弹幕, 赠礼, 签到任务等实验性账号写操作默认关闭, 需在设置中手动开启.

Windows NSIS 支持覆盖升级并保留用户数据. 若需退回 `v0.4.1` 及更早版本, 请先备份用户数据目录中的 `rooms/saved.json`. ZIP/tar.gz 为解压运行包, 不承诺将全部用户数据保存在解压目录中. 升级前退出旧进程, 不要同时运行共享同一用户数据目录的多个版本.
