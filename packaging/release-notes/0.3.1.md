# Fy1Sync 0.3.1

Windows 10 / 11 x64 桌面播放器, 将赛事画面, 主播解说和弹幕对齐观看.

## 下载

- `Fy1Sync-0.3.1-win-x64-nsis.exe`: 当前用户安装版, 无需管理员权限.
- `Fy1Sync-0.3.1-win-x64-portable.zip`: 免安装版, 解压后运行 `Fy1Sync.exe`.
- `SHA256SUMS.txt`: 本次附件的 SHA256 校验值.

本版本没有 Windows Authenticode 代码签名, 系统可能显示未知发布者或 SmartScreen 提示. 请核对仓库, 版本和文件校验值后再决定是否运行. 应用内更新包的 Ed25519 验签不等于 Windows 代码签名.

## 本次更新

- 改善 YouTube 直播取流兼容性. 上游仅返回受支持的分离音视频流时也可播放, 不再要求同时提供 HLS 地址. 保留备用抽取取得的有效格式, 必要时使用备用客户端进行一次有界重试; 最终失败显示具体分类与错误代码.
- 新增一键脱敏诊断报告: `设置 -> 通用 -> 取流工具 -> 导出诊断报告`. 即使取流尚未获得播放地址也能导出, 包含工具版本与来源, 网络类型, 各抽取阶段结果和播放摘要. 报告不包含 Cookie, token, 认证头, 媒体地址或用户目录, 不自动上传. 最近 20 次取流尝试仅保存在内存, 请在发生问题后退出应用前导出.
- 修复斗鱼弹幕已在房间显示却仍提示发送结果不确定的问题. 仅在严格匹配到本次本人弹幕后按成功处理, 保留底层回执与房间观察证据, 不自动重发. 迟到结果不会清掉后来编辑的草稿或影响切换后的房间与账号.
- 修复列表和画面悬浮菜单的弹幕复制, 增加成功与失败提示. 仅允许受信任应用窗口写入剪贴板, 不开放剪贴板读取.
- 修复摄像头框选在首帧尚未就绪且视频帧回调停止时, 预览一直黑屏, 无选框且无法保存的问题. 增加预览恢复和等待提示, 不改变原视频播放或贴边采样规则.
- 改善赛程刷新: 修复旧请求覆盖新赛果和后台更新未通知界面的问题. 查看选中赛事时, 若比赛进行中或将在 15 分钟内开始, 每分钟检查来源; 关闭面板或赛事已结束后保持 5 分钟刷新. `0:0` 改为提示赛果待更新, 来源读取时间不再被误认为赛果更新时间.
- 手动偏移默认使用大步长, 按住 `Shift` 使用小步长微调. 统一按钮悬停时的箭头与步长显示, 改善实际缓冲不足时的偏移提示, 并修复播放列表读写冲突可能导致缓冲停止的问题.
- 保留手动选择的 IEM 等赛事样式. 移除自动寻找与学习倒计时及自动按秒采样流程, 编辑器保留手动框选与字符标注.

## 使用边界

- 自动对齐仍为 `适配中`. 不同赛事的布局, 字体和清晰度尚未全部适配; 请在同一回合, 比分一致且倒计时正常变化时同步, 必要时手动微调.
- YouTube 的账号权限, 地区限制, 网络风控与上游改版仍可能影响取流. 本次兼容修复不保证解决所有取流失败.
- 赛程依赖 Liquipedia 的录入与更新, 不保证实时赛果. 更快的本机刷新无法补出上游尚未登记的比分, 请以直播画面为准.
- 斗鱼发送, 禁言, 赠礼和自动任务仍需显式启用. 本轮发布未执行真实账号写操作.
- 应用代码更新使用独立签名源. 本次未额外推送 `app-updates` 数据分支, 可直接下载本页安装包或免安装包升级.
