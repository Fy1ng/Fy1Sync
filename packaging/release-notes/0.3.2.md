# Fy1Sync 0.3.2

Windows 10 / 11 x64 桌面播放器, 将赛事画面, 主播解说和弹幕对齐观看.

## 下载

- `Fy1Sync-0.3.2-win-x64-nsis.exe`: 当前用户安装版, 无需管理员权限.
- `Fy1Sync-0.3.2-win-x64-portable.zip`: 免安装版, 解压整个目录后运行 `Fy1Sync.exe`.
- `SHA256SUMS.txt`: 本次附件的 SHA256 校验值.

本版本没有 Windows Authenticode 代码签名, 系统可能显示未知发布者或 SmartScreen 提示. 请核对仓库, 版本和文件校验值后再决定是否运行. 应用内更新包的 Ed25519 验签不等于 Windows 代码签名.

## 本次更新

- 改善斗鱼等平台直播和手动媒体直链兼容性. 普通媒体不再受账号 API 的固定域名和标准端口限制, 支持合法的非标准端口, 本机及局域网媒体服务.
- 保留 HLS 清单, 分片, AES 密钥和初始化片段的地址重写, 支持跨公网 CDN 跳转及签名参数. 外部清单自动访问未授权的本机或局域网来源时, 提示直接添加目标媒体地址.
- 修复系统代理中的 SOCKS5 和 PAC 多候选处理. 按系统返回顺序选择路由, 保留代理端 DNS 和明确指定的 DIRECT, 不因不支持某种代理而静默直连. SOCKS4 返回明确错误.
- 媒体连接池复用分片连接, 按来源, DNS, 代理, 播放上下文和凭据隔离. 改善持续 FLV, Range, 取消操作和代理握手超时的处理.
- 区分 DNS, 代理, 证书, HTTP, 超时, 格式和网络授权错误, 主画面及解说显示具体原因与操作提示. 诊断信息隐藏 Cookie, token 和签名媒体地址.
- 修复快速媒体源已产出缓冲片段却未通知就绪的竞态, 保留双路播放, 回退和既有直播重连行为. 录像选段导入支持 SOCKS5 和按 URL 决策的 PAC 路由.
- 修复 IEM 等赛程中的 ESL 频道名称匹配, 区分主台和副台, 恢复从赛程添加对应画面.
- 保留 Electron 沙箱, IPC 来源校验, 本地媒体访问能力验证, 账号 Cookie 隔离, 账号写操作确认和更新签名及完整性检查.

## 验证与使用边界

- 单元测试 6641 项通过, 包含长 GOP 缓冲和真实回环网络测试. 斗鱼, 虎牙, Bilibili 和 Twitch 已通过匿名真实直播解析, 缓冲及播放验收.
- YouTube 匿名验证遇到上游机器人检查, 未使用真实账号 Cookie 验证完整登录取流链路. 平台权限, 地区和网络风控仍可能影响播放.
- PAC 和 SOCKS5 已在隔离 Chromium session 及回环代理中验证. Fake-IP 部分使用合成 DNS; 未验证所有 Mihomo/Clash 实际配置. SOCKS5 依赖 Undici 的实验性支持.
- 当前发布以 Windows x64 为准, macOS/Linux 未运行完整桌面验收. 自动对齐仍为适配中, 必要时手动微调.
- 本轮未执行真实弹幕发送, 签到, 赠礼或禁言等账号写操作.
- 本次不推送 `app-updates` 数据分支, 请直接下载本页安装包或免安装包升级.
