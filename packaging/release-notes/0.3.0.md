# Fy1Sync 0.3.0

Windows 10 / 11 x64 桌面播放器, 将赛事画面, 主播解说和弹幕对齐观看.

## 下载

- `Fy1Sync-0.3.0-win-x64-nsis.exe`: 当前用户安装版, 无需管理员权限. 创建开始菜单快捷方式, 桌面快捷方式由安装完成页选择.
- `Fy1Sync-0.3.0-win-x64-portable.zip`: 免安装版, 解压后运行 `Fy1Sync.exe`.
- `SHA256SUMS.txt`: 本次附件的 SHA256 校验值.

本版本没有 Windows Authenticode 代码签名, 系统可能显示未知发布者或 SmartScreen 提示. 请核对仓库, 版本和文件校验值后再决定是否运行. 应用内更新包的 Ed25519 验签不等于 Windows 代码签名.

## 本次更新

- 安装包, 桌面应用, 任务栏和卸载程序使用新图标. 应用内左上角标识保持不变.
- IEM 样式包已加入签名赛事样式分发, 支持 GitHub / GitCode 选源和手动刷新. 本机草稿优先保留, 不被云端覆盖.
- 倒计时编辑器支持字符按钮即时标注, 防止同帧重复采样, 统一撤回, 自动按秒训练和字段开关. 左右比分共享字形, 左右暂停标记独立配置.
- 增加灰度, 自适应和 HSV 预处理, 局部参数推荐以及只读批量验收. 修复停止验收后重新开始, 禁用字段仍参与判定, 重启后本地录像无法继续使用的问题.
- 改善跨分辨率采样, 倒计时总置信度不再被冒号单独拉低, 但冒号仍接受匹配和格式校验.
- 修复弹幕列表在连续消息, 长文本换行和窗口缩放后无法可靠跟随底部的问题. 移除解说同时移除对应弹幕, 不会被迟到消息或页面切换恢复.
- 摄像头贴边改用局部彩色多帧与多尺度边界检测, 改善异色同亮, 软边和圆角识别. 有歧义时保留原框, 保存前可撤回, 分析不阻塞播放.
- 内置签名前端更新和完整应用更新机制. 更新需手动检查与下载; 前端包在下次启动生效并支持失败回退, 完整安装包须明确确认后运行安装向导.

## 使用边界

- 自动对齐标为 `适配中`. 不同赛事的布局, 字体和清晰度尚未全部适配; 请在同一回合, 比分一致且倒计时正常变化时同步. 必要时手动微调.
- 分辨率不是样式包白名单, 但低清晰度, 裁剪, 黑边和版式变化仍可能影响识别. 批量验收的读取成功率不等于真实准确率.
- 摄像头贴边依赖粗选框和画面边界, 无法保证区分所有静态矩形或严重遮挡. 保存前请确认预览结果.
- 赛事样式包分发已经上线. 应用代码更新使用独立签名源, 本次发布未额外推送 `app-updates` 数据分支, 对应在线清单尚未上线. 后续发布前端更新前需完成该源的正式分发配置; 当前可直接使用本页安装包升级.
- 便携版和开发实例不执行应用内完整安装升级. 用户需先安装一次包含在线更新机制的客户端, 才能使用后续签名前端更新.
- 斗鱼发送, 禁言, 赠礼和自动任务仍需显式启用, 真实账号操作不属于本轮发布回归范围.
