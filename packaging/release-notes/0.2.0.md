# Fy1Sync 0.2.0

Fy1Sync 把官方赛事画面和国内解说对到同一时间点：官方画面、解说声音、弹幕叠在一起看。这是第一个公开版本。

## 下载

| 文件 | 说明 |
| --- | --- |
| `Fy1Sync-0.2.0-win-x64-nsis.exe` | 安装版。安装到当前用户目录，不需要管理员权限；会建开始菜单快捷方式，桌面快捷方式在安装完成时选择 |
| `Fy1Sync-0.2.0-win-x64-portable.zip` | 免安装版。解压后运行 `Fy1Sync.exe` |

只支持 Windows 10 / 11 x64。

## 能做什么

- 同时播放官方源和解说源：YouTube、Twitch、斗鱼、哔哩哔哩、虎牙，也可以打开本地文件。
- 对齐两路画面：
  - 「回退画面」「快进画面」按住可连续调整，也可以点中间的秒数直接输入。
  - 「自动对齐」识别两边画面里的比赛倒计时。**目前标为「测试中」**，还没在足够多的真实比赛上验证，对不上时请手动调整。
- 斗鱼、虎牙弹幕叠加在画面上，也可以在侧栏列表里看；支持屏蔽、合并重复、收藏。
- CS2 赛程：比赛列表、队标、赛事级别，点一下打开对应直播。
- 收藏常看的直播间。
- 主播摄像头小窗，支持 WebGPU 超分。
- 画中画、截图和 GIF（截图与 GIF 需要在设置里打开）。
- YouTube 登录后可载入 1440p、4K 等高画质。

## 斗鱼写操作默认关闭

发送弹幕、+1、回复、禁言、赠礼、续牌，以及签到、鱼吧签到、定时弹幕、钓鱼、红包、宝箱任务，首版默认隐藏。需要时在「设置 → 斗鱼 → 实验性」里打开，打开前会再确认一次。这些操作会用你的账号真实执行，尚未逐项验收，可能触发平台风控。看弹幕、读取账号、关注、背包等只读功能不受影响。

## 网络与隐私

- 应用不开放任何网络端口。
- 账号登录在独立的 Chrome 窗口里由你自己完成，登录信息只保存在本机。
- 拉取 HTTPS 直播流时会校验服务器证书。如果你用的代理会解密 HTTPS（例如抓包工具），需要先把它的根证书装进 Windows 证书库，否则会载入失败。
- 检查更新只在你点「检查更新」时读取 GitHub Releases 的版本信息，不会自动下载或安装。

## 已知问题

- 自动对齐目前条件较苛刻：两路必须处在同一比分、都不在回放和回合间的冷却时间里，才可能成功。识别不到或被拒绝时请改用手动调整。
- 精简版 FFmpeg 只包含常见的直播编码，少数直链格式可能无法打开。
- 只在 Windows 上验证过。
