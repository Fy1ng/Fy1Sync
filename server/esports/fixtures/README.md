Each fixture retains the original listing container, table header and selected complete body rows. Cropping used parse5 source offsets and substring removal, without serializing or altering retained HTML. The retained rows deliberately include game-icon, team-placement and region links as interference. S/A/B captures contain 98/49/138 genuine tournament body rows respectively; broader counts that include other page links do not establish tier membership.

The observed selector is `.tournaments-listing table.table2__table > tbody > tr.table2__row--body > td.column__tournament > a[href]`. Class entities such as `table2&#95;&#95;row--body` are decoded by the HTML parser. Only the direct tournament-column anchor establishes membership; icon, placement, region, header and navigation links are excluded. Tests add clearly labelled synthetic navigation, selector-drift and C-tier variants. The C-tier variant demonstrates layout reuse and is not a captured C-tier response.

## Liquipedia wikitext source fixture

`liquipedia-source.json` was cropped exclusively from local captures in `.runtime-cache/reference/`. According to the capture notes, the original samples were retrieved on 2026-11-20 and 2026-11-21 via `action=query` with the prescribed User-Agent `Fy1Sync/<version> (local desktop app; sync@fy1ng.cn)`. No network requests were made while preparing the fixture. The local JSON does not store HTTP request headers, so no exact User-Agent version or request time was inferred. Content by Liquipedia contributors is used and shared under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

The fixture merges selected pages from several real queries into a `batchcomplete` / `query.normalized` / `query.pages` structure that tests can import directly. It preserves the original `pageid`, `ns`, `title`, and any revision IDs, timestamps, and slot types. Unrelated pages, the Bucharest `extlinks` list, and its corresponding `limits.extlinks` entry were removed. `revisions[0].timestamp` is the upstream page revision time, not the capture date; it remains absent where the original response omitted it.

The API links below point to the revision query for each page. Line numbers refer to decoded wikitext in the original `revisions[0].slots.main.content`, start at 1, and include both ends of each range. Cropping only joined substrings taken at the original line boundaries, preserving characters, case, tabs, empty values, comments, and line breaks. Each retained `Match` and its enclosing `Matchlist` / `Bracket` are fully closed. No synthetic matches or stream fields were added.
