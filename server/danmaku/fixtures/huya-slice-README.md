# 虎牙 HTTP 聊天 slice 流夹具

## 来源与用途

原始资料由指挥方于 2026-10-27 在宿主机匿名抓取, 房间 a16789. 夹具选自忽略目录中的 `slice-5.bin`, 同时段客户端报告的聊天时间范围为 09:06:08.386Z-09:09:28.622Z. 原始昵称、正文、UID、头像、payId、guid、签名和 Cookie 均不入库. source.packetIndices 使用原始文件的 0 基传输包编号, 只保留来源定位信息.

`huya-slice-real.json` 包含:

- singleChat: 真实单条 URI 1400 的结构, 脱敏后重新编码和压缩.
- singleGift: 真实单条 URI 6501, tag5=presenter-placeholder, tag6=viewer-placeholder, 名称替换为 gift-placeholder, 保留公开道具 ID 和数量.
- merged: 真实 frameNum=0 合并块中的 3 条 URI 6501 礼物, 重建每条记录的长度和序号.
- fragmented: 真实 frameNum=9 的 URI 6210 消息结构. 替换字段后重新 zlib 压缩, 按原来的 9 片数量重新分片, 保留可排序的片序号, 重写各片和传输包长度. 未将未知 URI 6210 扩为聊天.
- padding: 真实控制包的公共格式, 18 字节头后为 c8 00 84 03 和 900 个 ff.
- crossPacketBlock: 真实聊天结构的显式派生样本, 重新分成 3 个传输包, 使块头和压缩数据跨传输包边界. 原始连接是否恰在相同位置拆分不作主张.

因此这些是结构保真的真实脱敏重编码样本, 不声称字节等同原始抓包. 夹具期望值由独立 TARS AST 编码器推导, 不依赖生产解析器生成.

## 脱敏和隐私检查

运行 `node scripts/huya-slice-fixtures.mjs` 读取本地原始资料并重建夹具. 编码器只使用仓库已有的最小 TARS 编码思路, 不加载网页脚本、不执行远端代码、不新增依赖.

脱敏会递归遍历 TARS 结构, 把全部非公开字符串、未知字节字段和用户整数替换为占位. 聊天正文固定为 sanitized chat; 昵称固定为 viewer-placeholder; 主播昵称单独使用 presenter-placeholder; 头像固定为 example.invalid; 主播 UID 也替换为 12345. lMsgId 使用独立合成值, 不保存原始消息 ID. 传输头、配置时间、序号和分组名同样重写. 随后重建 TARS 字符串/字节/集合长度, zlib 数据、片长度、合并记录长度以及传输包长度.

生成时对干净 AST 使用字符串白名单和整数替换规则核验, 并与原始字段中提取的身份候选值做交叉检查. 本次 491 个原始身份/文本候选, 剩余匹配 0. 原始候选集合仅在本地内存, 不输出原文. 公开道具 ID/数量和协议 URI 作为协议字段保留. HTTP 签名请求/响应夹具尚未制作, 签名实现写入被自动审批拒绝; 此文件不包含签名或签名 URL.

## 分片规则及有界解析

网页 mainlib.js 仅作为行为参考, 未复制其实现. 位置以本地脚本 UTF-16 字符偏移计数:

- 99600 附近 ComFrame.append: 按每片 seqNum 排序, 去除重复片, 收齐 frameNum 片再拼接 streamData.
- 110276 的 sliceOneInMoreCompress: 收齐后统一 inflate, 再按单条消息处理.
- 110789 的 _sliceMoreInOne: 合并记录为 u32LE 长度(含 8 字节头)、u32LE 消息序号、WSPushMessage.

实际块头中的 u16LE@5 是片数 frameNum, 0=合并、1=单条、2 以上=一条消息的分片数量, 不把 0x09 当作固定类型. u16LE@13 是当前片的压缩 payload 长度; 后面还有 u32LE 条目数及每条 u8 key/u32LE value 的配置 map. 旧粗略探针把这段配置拼进压缩串, 导致大消息解压失败. 正确做法是只取每片 payload, 按 u16LE@3 排序后合并, 再一次解压. 当前抓包的 20 条分片消息全部解开.

解析器分别限制传输包 65535 字节、每块 payload 65535 字节、配置项 32、分片数 64、待组装消息 16、全部待组装压缩数据 512 KiB、单次解压输出 1 MiB、合并记录数 512. 分片 5 s 后失效. 序号用低 16 位检测连续性和回绕, 不补拉. reset 清理连接状态并保留累计统计.
